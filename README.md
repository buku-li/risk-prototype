# 风控平台一期 · 原型（单文件版）

一个自包含 HTML，内嵌 6 个页面，零外部依赖，双击即可打开：

| # | 页面 | 说明 |
|---|---|---|
| 1 | 内容审核工作台 | 待办池、领取任务 |
| 2 | 个人审核记录 | 审核员个人工单 |
| 3 | 内容审核记录 | 机审/人审结果、违规原因（三级标签）、管理员结论变更 |
| 4 | 举报审核工作台 | 举报待办池 |
| 5 | 个人记录 | 举报审核员个人工单 |
| 6 | 举报记录 | 举报处理结果、管理员结论变更 |

## 访问方式

- GitHub Pages：`https://<用户名>.github.io/<仓库名>/`
- 或直接下载 `index.html` 到本地双击打开（离线可用，无需服务器）

## 更新流程

替换根目录 `index.html` 后提交推送即可，Pages 会在 1–2 分钟内自动更新。

```bash
cp /c/Users/13326/Desktop/审核平台/风控平台原型_单文件版.html ./index.html
git add index.html && git commit -m "更新原型" && git push
```

## 说明

- `.nojekyll`：跳过 Jekyll 构建，避免 Pages 对静态文件做多余处理
- 图片与视频已内联为 data URI，无任何外链请求
